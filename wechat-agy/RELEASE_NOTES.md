# 大肥鱼桌面版 0.2.7

把微信大肥鱼托管工具封装为独立 Windows 客户端：解压可运行，可安装桌面/开始菜单快捷方式，
自带 Python 环境。新增启停、连接设置、运行状态、动画表情字典、群聊归纳与人格编辑入口。

- 为指定关系的好友加入有频率控制的主动关心；生成在后台运行，不阻塞普通私聊。
- 指定联系人可单独设置关系和温暖助手口吻；多位好友的私聊运行状态分别记录。
- 为指定关系的好友新增本机已下载的 Excel / Word 文件任务试用通路；文件单独留存，发送不确定时停下待核。真实微信收发仍需在目标环境验证。
- 群聊和私聊的涉政话题保持静默，优先于 @ 兜底、表情和后台研究；判定不确定或不可用时不发送。
- 结合最新话题和待发内容判断；普通证券与日常话题不按领域一概屏蔽。

- 指定好友的材料修改、撰写和认真问题可调用已登录 Codex 的 GPT-6 Astra Ultra；闲聊仍使用 AGY Low。
- 生成工作回复时收到新的私聊要求，会合并后重新生成；联网问题继续使用有来源校验的 AGY 搜索链。
- 新增对明确选定的好友处理文字私聊；独立保存上下文、模型会话与待回复队列。
- 私聊与群聊共用发送锁，并核对独立窗口的微信 ID；未读取的图片、语音和无法判断的附件不自动回应。

- 日常闲聊使用 AGY Gemini 3.8 Flash Low；认真问题、联网查证和记忆使用 High，后台查询不阻塞接话。
- 缩短普通接话冷却与消息合并等待；模型临时失败时保留未回答的 @ 并重试。
- 支持真实 @ 回应，按成员 ID 和当前群昵称找到原提问者。
- 自动收集原表情、理解多帧动作、用稳定编号选图；识图失败或不确定时调用本机 Codex。
- 修复点击失败后仍继续全局粘贴、导致文字误入其他应用的问题。文字改为控件定向写入；
  发送前确认目标窗口，表情和 @ 的键盘步骤失焦即中止，不回退到无校验按键。
- 个人资料独立保存；发行包不包含账号、聊天记录、成员侧写、表情原件或登录凭据。

需要 Windows 11 x64、已登录的微信与 AGY CLI；私聊工作任务和补充识图需要已登录的 Codex CLI。
完整解压后运行 `DaFeiYu.exe`，或双击 `Install.cmd` 创建快捷方式。详见包内 `DESKTOP.md`。
