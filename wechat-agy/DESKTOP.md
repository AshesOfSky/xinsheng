# 大肥鱼 · Windows 桌面客户端

版本 0.2.2，Windows 11 x64。自带 Python 运行环境，解压后即可打开 `DaFeiYu.exe`。

## 安装和第一次启动

1. 完整解压下载的 ZIP，不要只单独取出 EXE。
2. 双击 `Install.cmd`，程序会安装到当前用户目录，并添加桌面和开始菜单快捷方式。
   也可以直接运行解压目录内的 `DaFeiYu.exe`，不需要管理员安装。
3. 微信保持登录，AGY CLI 已安装并使用自己的账号登录。私聊工作任务和补充表情识图需要已登录的 Codex CLI。
4. 在「连接设置」检测账号、读取群聊、选择目标群并保存。
5. 在微信打开目标群，推荐保留独立群聊窗口；回到「运行概览」点「启动大肥鱼」。

模型与 CLI 的实际可用额度由各自账号决定。本包不附带微信、AGY、Codex、账号或登录状态。
首次启动会导入所选群在本机可读的历史，用于留档和理解语境；不会批量补答旧消息。

## 四个页面

- **运行概览：**启停后台，查看 Low/High 是否就绪、最近回复、耗时、表情数量和错误。
- **表情字典：**逐张查看原图和动画，编号、含义、适合/避免场景、识图来源与收藏状态。
- **连接设置：**选择真实微信账号与群聊，设置普通接话间隔，查看 CLI 是否安装。
- **档案与人格：**打开群聊归纳、成员记忆和运行日志；编辑人格，保存前自动备份原文。

关闭客户端窗口后，后台继续运行。点「停止后台」才会停止监听和生成，不会退出微信。
已经提交的消息不能撤回，发送结果不明确时也不会自动重发。

## 指定好友私聊

私聊仅处理本地 `data/config.json` 的 `private_contacts` 中明确选定的联系人，
每位联系人使用独立档案和模型会话。配置示例：

```json
"private_contacts": [{"id": "wxid_example", "name": "联系人显示名"}]
```

微信需保持该联系人的独立私聊窗口打开；发送前会核对窗口对应的微信 ID，且不覆盖已有草稿。
停机期间收到的消息会在恢复后排队，结果不明确的发送不会自动重发。收到图片、语音或附件时，
当前版本会请对方贴出需要处理的文字，不能直接读取附件内容。私聊闲聊使用 AGY Low；
材料撰写、修改、审阅和其他认真问题使用已登录 Codex 的 GPT-6 Astra Ultra，消耗 Codex 额度。
需要联网查证的请求仍由 AGY High 搜索并核验来源。私聊文本会发送给相应模型服务处理。
工作模型执行较慢时，如果对方补充要求，会合并新消息后重新处理，避免先发旧稿。

## 本地资料

新安装默认保存在 `%LOCALAPPDATA%\DaFeiYu`，程序升级与个人资料分开。
已有源码版资料可以直接继续使用，不需要复制或覆盖：

```powershell
.\DaFeiYu.exe --workspace "E:\你的项目\wechat-agy"
```

安装时传入 `install.ps1 -Workspace "已有资料目录"`，生成的快捷方式会记住该路径。
已有群聊档案的目录不能直接改成另一个账号或群，避免混用成员记忆；换群请选新的空目录。

运行期间请保持电脑唤醒、微信登录。文字直接写入已绑定的微信控件，再点击微信发送按钮；
表情和原生 @ 需要短暂使用焦点和剪贴板，失焦时取消后续按键。不要把它视为微信协议接口。
客户端不会为修复发送而在其他窗口粘贴或按回车；发送后从目标群数据库确认实际结果。

群聊内容和相关成员观察会发给所配置的模型服务进行推理，本工具不是完全离线处理。
原始记录、数据库缓存、成员记忆、表情和账号配置保留在本机，不在 GitHub 发布包中。

## 构建

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller==6.22.3
.\build.ps1
```

构建会运行测试、生成 EXE，并在一个新的空目录中检查冻结程序的界面、依赖和资源。
产物是 `release/DaFeiYu-Windows-x64-v0.2.2.zip`。GitHub Actions 执行相同步骤。
本版本没有代码签名；Windows 首次打开可能显示未知发布者提示。

依赖许可保存在包内 `third-party`。本工具与微信、Google、OpenAI 均无官方隶属关系。
