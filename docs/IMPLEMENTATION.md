# 实现说明

- **接入层：**持久 OneBot WebSocket，按 echo 关联接口回执，处理私聊与本人回流。
- **存储层：**SQLite 保存消息、草稿、画像、记忆、历史进度和回放；中文示例检索使用 FTS5。
- **回复引擎：**连续消息合并、串行生成、旧草稿取消、人工确认、自动回复、接管和未知发送结果处理。
- **模型层：**调用已登录的 Codex CLI，结构化最终输出只允许回复、需要人工或跳过三类结果；QQ 发送由本地应用控制。
- **历史分析：**按消息 ID 去重，保留真实分页覆盖、来源与时间，排除应用回复作为本人训练样本。
- **界面：**会话、历史风格、记忆、连接运行四个页面，另提供 Windows 桌面外壳。

历史同步不触发补发；模型使用的历史样本与事实保留时间边界。未支持媒体进入人工处理，不将看不到的内容当作已识别。

代码测试与真实账号验收不同。第三方 QQ / NapCat 兼容性、个人历史完整性、模型可用性、风格贴近程度及长期运行稳定性，需要在使用者环境中验证。
