# 心声 · QQ 私聊回复助手

心声是运行在 Windows 上的 QQ 私聊回复助手。它通过 NapCat 和 OneBot 接收指定联系人的新消息，使用本机已登录的 Codex CLI 生成可编辑草稿，支持人工确认发送、自动回复、历史风格参考和桌面新消息提醒。

## 能做什么

- **人工确认：**收到消息后生成草稿，使用者修改、确认后才发送。
- **自动回复：**仅处理启用后收到的新消息，支持暂停与人工接管。
- **历史与风格：**导入可读聊天历史，提炼本人表达方式，编辑画像和带来源的示例。
- **关系记忆：**保留来源与时间，自动提取的事实先标为待核。
- **离线回放：**用历史场景生成候选回复作对照，不向 QQ 发送。
- **桌面工作台：**独立 Windows 窗口、QQ 登录入口和任务栏新消息提醒。

首版支持文字和 QQ 系统表情。图片、语音、引用等内容进入人工处理；每轮发送一条 QQ 消息，不主动定时问候。

## 工作方式

QQ / NapCat ↔ OneBot WebSocket ↔ 本地 Node.js 服务 ↔ Codex CLI

React 管理面板和 WPF / WebView2 桌面窗口共用本地服务，SQLite 保存会话、草稿、画像与记忆。默认监听本机，不开放局域网或公网。

**模型推理在云端完成。**生成回复时，所选聊天上下文、相关事实和历史示例会提交给 Codex 使用的模型服务；本项目不等于完全离线处理。

## 开始使用

需要 Node.js 24、pnpm 10、已安装并登录的 Codex CLI，以及兼容的 QQ / NapCat 运行环境。桌面端另需 .NET Desktop Runtime 10 和 Microsoft Edge WebView2 Runtime；从源码构建桌面端需要 .NET SDK 10。

1. 克隆仓库并安装依赖：

   ~~~powershell
   pnpm install --frozen-lockfile
   pnpm check
   ~~~

2. 按 [运行环境说明](docs/RUNTIME.md) 准备 QQ 和 NapCat，在首次接入现有资料前备份。
3. 运行“启动QQ连接.cmd”，使用自己的账号登录；再运行“启动心声.cmd”打开工作台。
4. 在“连接与运行”核对承担回复的 QQ、选择目标联系人，并选择自己 Codex 账号可用的模型。首次使用建议保持“确认后发送”。
5. 可选：按 [桌面端说明](docs/DESKTOP.md) 构建独立窗口。

本仓库不提供账号、连接令牌、登录状态、聊天记录、画像、关系记忆或预置个人配置；首次使用需自行配置。

## 回复规则

| 情况 | 行为 |
| --- | --- |
| 连续消息 | 默认等待 3 秒合并，同一会话串行生成 |
| 生成期间收到新消息 | 取消旧结果，基于最新上下文重新生成 |
| 确认模式下手动回复 | 旧草稿失效，下一条对方消息仍会生成草稿 |
| 自动模式下手动回复 | 暂停自动处理，等待使用者恢复 |
| 明确暂停 | 保存新消息但不生成；恢复不补发旧消息 |
| 发送结果不明确 | 标为待核，不自动重复发送 |
| 导入、重连与重启 | 不因历史同步触发旧消息补发 |

应用发送回流按消息 ID 关联，不当作本人手动接管。生成内容不得编造已完成的行动、现实安排或承诺。

## 历史与风格

支持最近 90 天、自选时间或全部可读历史，保留分页进度、消息 ID 和实际覆盖范围。接口返回成功不代表已经取得全部漫游历史。

风格只从本人真实发言中提取，应用生成的回复不作为本人样本。画像和示例可编辑；关系事实可查看来源、确认或移除。每次生成使用最近 40 条消息、摘要、相关事实和最多 6 段历史示例。

离线回放最多选择 20 段历史场景，训练和输入时间早于对应原回复；表达是否贴近本人由使用者判断。参见 [实现与验证](docs/IMPLEMENTATION.md)。

## 开发

~~~powershell
pnpm dev
pnpm check
dotnet run --project desktop-tests/Echo.Desktop.Tests.csproj -c Release
~~~

开发界面为 http://127.0.0.1:5173，本地服务为 http://127.0.0.1:23210。不要同时启动两个使用同一数据目录的服务。

模型连接探针会产生真实模型调用，但只使用合成资料，不向 QQ 发送：

~~~powershell
pnpm test:codex
pnpm exec tsx scripts/check-codex.ts --analysis
~~~

## 文件说明

| 目录 | 内容 |
| --- | --- |
| src/server | QQ 协议接入、回复引擎、历史分析、存储与接口 |
| src/client | React 工作台 |
| src/shared | 消息段与共享类型 |
| desktop | WPF / WebView2 桌面窗口 |
| desktop-tests | 桌面提醒规则检查 |
| scripts | Windows 启停、备份与构建脚本 |
| tests | 合成数据和模拟传输测试 |

运行时生成的 data、runtime、backups、test-results 和编译输出均被 Git 忽略。发布时的资料边界见 [隐私说明](docs/PRIVACY.md)。
